Frequently Asked Questions

Is YTDLPY free to use?

Yes, YTDLPY is completely free and open-source software. You can use it without any limitations.

Is it safe to download and use?

YTDLPY is safe to use and does not contain malware or adware. It's open-source, so you can verify the code yourself on GitHub.

Which platforms are supported?

YTDLPY currently supports Windows. Support for macOS and Linux may be added in future versions. Currently, Linux and macOS are only supported if you compile the program yourself using Python from https://github.com/dddevid/YTDLPY.

Can I download playlists?

Currently, YTDLPY supports downloading individual videos. Playlist support is planned for a future update.

What quality options are available?

For MP4 videos, you can choose between high (best available), medium (720p), and low (480p). For MP3 audio, you can select high, medium, or low bitrate options.
